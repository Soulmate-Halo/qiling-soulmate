# 开源范围说明 / Open Source Scope

本文档明确器灵 Soulmate 在 `qiling-soulmate` 公开仓库中**开放什么、不开放什么**，帮助社区正确理解本仓库的定位与边界。

## 结论

**本仓库不是开源软件仓库，未发布产品源码，也不附带任何开源许可证（LICENSE）。**

`qiling-soulmate` 是与主流 AI 工具官方公开仓库相同思路的**社区与运营入口**。

## 开放范围（Open）

本仓库公开以下内容：

1. **产品信息与使用理念**
   - 产品定位、核心能力（多 AI CLI 协同、任务拆解、动态路由、上下文治理、成本优化）；
   - 品牌介绍与使用引导（见 README）。

2. **公开路线图（Roadmap）**
   - 未来方向与规划（见 [ROADMAP.md](./ROADMAP.md)），不承诺具体日期。

3. **反馈渠道**
   - Bug 报告、需求建议（通过 Issue 模板提交）；
   - 安全漏洞私密报告（走 GitHub Security 渠道）。

4. **社区协作**
   - 文档改进、反馈与讨论（通过 Issue / PR / Discussions）。

## 闭源范围（Closed）

以下内容**保持闭源，不在本仓库发布**，请勿在此索取或上传：

| 类别 | 说明 |
| --- | --- |
| 桌面端核心运行时 | 主进程、渲染进程、桌面应用本体及其实现 |
| 编排策略 | 多 CLI 协同、任务拆解、动态路由、上下文治理、成本优化的内部实现 |
| 商业服务端 | 登录、商业后端、云服务与相关接口 |
| 生产配置 | 部署配置、环境配置、凭据类配置 |
| 密钥与凭据 | 任何密钥、令牌、账号、内部服务器信息等 |

## 为什么这么做

器灵 Soulmate 提供的是**闭源商业产品**。公开仓库聚焦于社区、反馈与运营，可以让用户与合作伙伴：

- 了解产品定位与方向；
- 便捷地反馈问题与需求；
- 参与文档与协作流程建设；

同时避免：

- 泄露核心运行时与编排策略的实现细节；
- 将内部服务器、密钥、账号等敏感信息暴露于公开环境；
- 造成「本产品可自由构建运行」的错误认知。
